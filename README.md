# PrivacyFlow

브라우저에서 개인정보 처리 활동과 전달 흐름을 그리는 편집기입니다. 실제 개인정보 값 대신 합성 예제, 개인정보 **항목명**, 처리 활동만 입력하세요. 도면은 법적 적합성이나 인증을 보장하지 않습니다.

## 실행 및 배포

Node.js 22.12 이상에서 `npm ci`, `npm run dev`로 로컬 실행합니다. `npm run build`는 `dist/`에 정적 사이트를 생성합니다. GitHub Pages 배포는 저장소의 Pages workflow를 사용합니다.

## 편집과 출력

처리 단계별 노드와 방향 흐름을 추가하고, 목록·속성 폼에서 상세 내용을 수정합니다. 캔버스 드래그와 선택 노드의 방향키 이동은 프로젝트 좌표로 저장됩니다. 여러 장을 만들고 이름을 변경·복제할 수 있으며 실행 취소/다시 실행을 지원합니다. 좁은 화면(900px 이하)에서는 도면·목록·속성 화면을 전환해 기존 기능에 접근합니다. 별도의 모바일 터치 편집 모드는 제공하지 않습니다.

JSON은 모든 프로젝트 정보와 상세 속성을 보존합니다. PPTX는 도면과 전체 속성표를 담고, PNG·SVG·PDF는 도면 출력이므로 전체 속성 복원에는 JSON 백업을 사용하세요.

## 저장과 개인정보

자동 저장은 브라우저의 평문 localStorage에 저장하며, JSON 백업도 평문입니다. Web Locks가 지원되는 브라우저에서 업데이트된 앱 탭끼리 저장 충돌을 감지합니다. 구버전 앱 탭과 동시에 편집하지 마세요. 손상된 저장 자료는 원문을 다운로드하기 전 자동으로 덮어쓰지 않습니다. 충돌·저장 실패·Web Locks 미지원에서는 현재 편집 JSON을 수동으로 백업하고 저장 상태 안내를 확인하세요. 브라우저 데이터 삭제 시 로컬 저장은 사라질 수 있습니다. 암호화·로그인·서버 동기화는 제공하지 않습니다.
